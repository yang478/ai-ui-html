如何配置 API

  • 前往 OpenAI 获取 API Key，或使用兼容 OpenAI Chat Completions 的代理
  • 点击右上角齿轮图标进入“OpenAI 设置”，填入 Base URL、模型与 API Key
  • 也可在部署时提供 env.json 或 .env，无需手动填写
