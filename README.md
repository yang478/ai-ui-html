## 🚀 快速开始

### 1. 打开应用
```bash
# 直接用浏览器打开
open index.html
# 或双击 index.html 文件
```

### 2. 使用步骤
1. **选择设计目的** - 从8个选项中选择
2. **定义视觉风格** - 从6种风格中选择
3. **配置功能组件** - 从18个类别中选择100+组件
4. **复制提示词** - 自动生成，一键复制

### 3. 使用AI助手
1. 点击左上角 ⚙️ 设置按钮
2. 配置API密钥
3. 在底部聊天区域与AI对话

## 🎨 设计原则

### Apple设计语言
- 大量留白
- 毛玻璃效果 (backdrop-filter)
- 流畅动画 (cubic-bezier)
- 清晰的视觉层次

### 响应式设计
- 桌面端：65%/35% 布局
- 平板端：55%/45% 布局
- 移动端：垂直堆叠

## 🔍 搜索功能

支持实时搜索组件：
- 搜索"输入" → 找到所有输入相关组件
- 搜索"表格" → 找到表格和列表组件
- 搜索"导航" → 找到导航相关组件

## 💾 本地存储

应用使用localStorage保存：
- 用户选择 (目的、风格、组件)
- API配置 (密钥、模型)
- 对话历史 (聊天记录)
- 设置偏好 (主题、格式)

## 🔒 隐私安全

- ✅ 数据不上传到第三方服务器
- ✅ 纯前端应用
